# Strong Scaling Study Report

Generated by `scripts/compute_strong_scaling.py`.

## What was measured

- Pure MPI domain-decomposition solvers: core count = MPI ranks.
- Hybrid MPI/shared-memory solvers: core count = MPI ranks × threads per rank.
- OpenMP solvers: core count = OpenMP threads.
- Speedup is computed against the smallest available core count for the same solver and same case.
- Efficiency is speedup divided by the ideal core-count ratio.
